ЦИФРОВОЕ ПОРТФОЛИО — ТРАВЕННИКОВ КИРИЛЛ

Просмотр:
1. Распакуйте архив полностью.
2. Откройте index.html в браузере.

Публикация:
Можно загрузить index.html, style.css и папку assets в GitHub Pages.
В настройках репозитория GitHub откройте Settings -> Pages и выберите Deploy from a branch,
ветку main и папку /(root). После публикации GitHub покажет публичную ссылку.

Сайт содержит разделы: Главная / О себе, Резюме / Карьера, Кейсы, Образование и сертификаты,
Навыки, Отзывы и рекомендации, Контакты.
